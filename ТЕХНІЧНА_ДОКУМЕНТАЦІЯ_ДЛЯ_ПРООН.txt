## 1. Що це за інструмент?

**Інструмент оцінки доступності молодіжних центрів** — це веб-опитування, яке допомагає українським молодіжним центрам оцінити, наскільки вони доступні для людей з різними потребами, зокрема:

- Людей на інвалідних візках
- Людей з порушеннями зору
- Людей з порушеннями слуху
- Батьків з візочками
- Людей з обмеженою мобільністю
- Та 12 інших категорій користувачів (всього 17)

Після проходження приблизно 160 питань у 4 розділах інструмент:
- Розраховує бали доступності для кожної категорії користувачів
- Надає конкретні рекомендації щодо покращення
- Генерує PDF-звіти, які можна завантажити
- **Автоматично надсилає результати адміністратору ПРООН на email**

## 2. Як він був створений?

### Використані технології (спрощено)

| Технологія | Що робить | Аналогія |
|------------|-----------|----------|
| **React** | Основний будівельний матеріал для сайту | Як цеглинки LEGO для сайтів |
| **Vite** | Допомагає розробникам працювати швидше | Як електроінструмент для будівельників |
| **JavaScript** | Мова програмування | Мова, яку розуміє комп'ютер |
| **CSS** | Робить сайт гарним | Як фарба та декор |
| **html2pdf.js** | Створює PDF-документи | Як віртуальний принтер |

### Як це працює разом

Уявіть створення сайту як будівництво будинку:

1. **React** забезпечує структуру (стіни, кімнати, двері)
2. **CSS** забезпечує зовнішній вигляд (кольори фарби, меблі)
3. **JavaScript** забезпечує функціональність (електрика, сантехніка)
4. **Vite** допомагає будівельникам працювати ефективно
5. **html2pdf.js** створює паперові копії того, що на екрані

Весь код зберігається в папках на комп'ютері, і коли хтось відвідує сайт, браузер завантажує цей код і відображає його.

### Чотири розділи оцінювання

| Розділ | Зміст | Мета |

| **Розділ 2** | Програмна діяльність | Які послуги надає центр, статистика відвідувачів |

### Типи питань

Інструмент використовує різні типи питань залежно від потрібної інформації:

- **Текстові поля** — Для введення відповідей (назва центру, адреса)
- **Випадаючі списки** — Вибір одного варіанту зі списку (вибір області)
- **Перемикачі (radio)** — Вибір одного варіанту (Так / Частково / Ні)
- **Прапорці (checkbox)** — Вибір кількох варіантів (які послуги надаються)
- **Матричні питання** — Таблиця варіантів (оцінка кількох пунктів)

## 4. Як це працює?

### Повний процес

```
БРАУЗЕР КОРИСТУВАЧА                СЕРВЕРИ VERCEL              СЕРВІС EMAIL
     |                                  |                          |
     |  1. Користувач завершує          |                          |
     |     оцінювання                   |                          |
     |                                  |                          |
     |  2. Завантажується сторінка      |                          |
     |     результатів                  |                          |
     |     - Розраховуються бали        |                          |
     |     - Генеруються рекомендації   |                          |
     |                                  |                          |
     |  3. АВТО: Генерація PDF-звітів   |                          |
     |     (у браузері користувача)     |                          |
     |                                  |                          |
     |  4. АВТО: Відправка на сервер    |                          |
     |--------------------------------->|                          |
     |                                  |                          |
     |                                  |  5. Надсилання email     |
     |                                  |     з PDF-вкладеннями    |
     |                                  |------------------------->|
     |                                  |                          |
     |                                  |                          |  6. Email доставлено
     |                                  |                          |     до скриньки адміна
     |                                  |                          |
     |  7. Показ повідомлення           |                          |
     |     про успіх                    |                          |
     |<---------------------------------|                          |
     |                                  |                          |
     |  8. Користувач також може        |                          |
     |     завантажити PDF вручну       |                          |
```

### Пояснення крок за кроком

1. **Користувач завершує оцінювання** — Всі відповіді зберігаються в пам'яті браузера (називається "localStorage"). Це означає, що якщо ви випадково закриєте браузер, ваш прогрес збережеться.

2. **Завантажується сторінка результатів** — Сайт розраховує бали та генерує рекомендації на основі відповідей.

3. **Автоматична генерація PDF** — Сайт створює два PDF-документи в браузері користувача:
   - **Звіт з результатами** (~500КБ-1МБ) — Бали та рекомендації (для молодіжного центру)
   - **Повний звіт відповідей** (~1-1.5МБ) — Всі відповіді (для адміністрації ПРООН)

4. **Автоматичне надсилання email** — Протягом кількох секунд після завантаження сторінки результатів система автоматично:
   - Надсилає PDF-звіти на сервер Vercel
   - Сервер пересилає їх до сервісу email (Resend)
   - Email з PDF-вкладеннями доставляється адміністратору

5. **Підтвердження успіху** — Користувач бачить зелене повідомлення: "Результати автоматично відправлено адміністратору на email!"

6. **Ручні опції** — Користувач також може:
   - Завантажити PDF безпосередньо на свій комп'ютер
   - Вручну повторно надіслати email за потреби

### Зберігання даних

| Що | Де | Як довго |
|----|-----|----------|
| Відповіді користувача під час оцінювання | Локальне сховище браузера | Поки не очищено дані браузера |
| Завершені PDF-звіти | **Email-вкладення** | Назавжди (у скриньці адміна) |
| Email-сповіщення | Логи сервісу Resend | Згідно з їхньою політикою |

**Важливо:** PDF-файли надсилаються як вкладення до email і зберігаються в поштовій скриньці адміністратора. Хмарне сховище не використовується, тому немає обмежень на зберігання або терміну дії. Файли залишаються доступними, поки email не видалено.

### 1. Vercel (Хостинг сайту)

**Що це:** Vercel — це хмарна платформа, яка хостить (запускає) наш сайт. Уявіть це як оренду місця в торговому центрі для вашого магазину — Vercel надає будівлю, електрику та охорону, а ми надаємо вміст магазину.

**Чому ми це обрали:**
- Безкоштовний тариф для некомерційних проектів
- Автоматичні оновлення при зміні коду
- Швидке завантаження по всьому світу

**Що Vercel робить для нас:**

- Запускає "серверлес-функції" (маленькі програми, що надсилають email)
- Автоматично розгортає оновлення при зміні коду

### 2. Resend (Сервіс email)

**Що це:** Сервіс, який надсилає email програмно (автоматично з нашого сайту).

**Як ми його використовуємо:** Після кожного завершеного оцінювання Resend надсилає email адміністратору ПРООН з:
- Назвою центру
- Датою завершення
- **PDF-звітами, прикріпленими безпосередньо до email** (зовнішні посилання не потрібні)

**Чому ми це обрали:**
- Безкоштовний тариф включає 3,000 email/місяць (більш ніж достатньо)
- Підтримує вкладення файлів до 40 МБ на email
- Файли залишаються в поштовій скриньці назавжди (без терміну дії)
- Просто налаштувати
- Надійна доставка (~>99% успішності)

## 6. Про хостинг Vercel

### Що таке Vercel?

Vercel — це хмарна платформа, заснована у 2015 році (спочатку називалася "Zeit"). Вона спеціалізується на хостингу сайтів, особливо створених на сучасних технологіях типу React.

**Аналогія:** Якщо ваш сайт — це телешоу, то Vercel — це телеканал, який транслює його глядачам по всьому світу.

### Як Vercel працює для нас

```
КОМП'ЮТЕР РОЗРОБНИКА              GITHUB                    VERCEL
        |                            |                         |
        |  1. Написання коду         |                         |
        |                            |                         |
        |  2. Завантаження коду      |                         |
        |--------------------------->|                         |
        |                            |                         |
        |                            |  3. Vercel виявляє      |
        |                            |     новий код           |
        |                            |------------------------>|
        |                            |                         |
        |                            |  4. Vercel збирає       |
        |                            |     сайт                |
        |                            |                         |
        |                            |  5. Сайт працює         |
        |                            |     по всьому світу     |
        |                            |                         |
```

### Автоматичні оновлення

Одна з найкращих функцій Vercel: щоразу, коли ми оновлюємо код і завантажуємо його на GitHub (сервіс зберігання коду), Vercel автоматично:

1. Виявляє зміни
2. Перезбирає сайт
3. Публікує нову версію

Це відбувається приблизно за 1-2 хвилини, без простою (користувачі ніколи не бачать сайт "на реконструкції").

### Де насправді працює сайт?

Vercel має сервери в багатьох локаціях по всьому світу (називається "edge network"). Коли користувач в Україні відвідує сайт, він підключається до найближчого сервера, що робить завантаження швидшим.

### Важливі обмеження

#### Обмеження Hobby-плану

1. **Лише один користувач** — Лише одна особа може мати доступ до панелі керування Vercel для управління проектом
2. **Без комерційного використання** — Не можна використовувати для діяльності, що приносить дохід (некомерційне використання дозволено)
3. **Без Git-організації** — Не можна підключати до організаційних акаунтів GitHub
4. **Без командних функцій** — Без співпраці, спільного доступу або командної аналітики
5. **Ліміти використання** — При перевищенні сервіс призупиняється до наступного 30-денного циклу (без оплати, просто чекати)

#### Обмеження розміру запиту

Vercel має **ліміт 4.5 МБ** для даних, що надсилаються до серверлес-функцій. Наші PDF оптимізовані, щоб залишатися в цих межах:
- PDF результатів: ~500КБ-1МБ
- PDF повних відповідей: ~1-1.5МБ
- Всього: ~1.5-2.5МБ (значно менше ліміту 4.5МБ)

#### Коли оновлюватися

Розгляньте оновлення до Pro ($20/місяць) якщо:
- Кілька людей повинні керувати сайтом
- Проект отримує комерційне фінансування
- Потрібна розширена аналітика
- Потрібна пріоритетна підтримка

## 8. Обслуговування та оновлення

### Хто чим керує

| Компонент | Керує | Необхідні навички | Частота |
|-----------|-------|-------------------|---------|
| Код сайту | Розробник | Програмування (React, JavaScript) | За потреби |
| Хостинг Vercel | Автоматично | Немає (самообслуговування) | — |
| Питання/контент | Редактор контенту | Редагування JSON-файлу | За потреби |
| Email-сповіщення | Автоматично | Немає | — |
| PDF-звіти | Автоматично (надсилаються як email-вкладення) | Немає | — |

### Як оновити питання

Питання зберігаються у файлі `questions.json`. Щоб додати, змінити або видалити питання:

1. Відкрийте файл у текстовому редакторі
2. Знайдіть питання, яке хочете змінити
3. Внесіть зміни, дотримуючись існуючого формату
4. Збережіть файл
5. Завантажте на GitHub
6. Vercel автоматично оновить робочий сайт

**Примітка:** Це вимагає базового розуміння формату JSON або допомоги розробника.

### Резервне копіювання та відновлення

| Що | Метод резервного копіювання | Час відновлення |
|----|---------------------------|-----------------|
| Код сайту | GitHub зберігає всі версії | Миттєво (повернення до попередньої версії) |
| PDF-звіти | Поштова скринька адміністратора | Завжди доступні (якщо email не видалено) |
| Відповіді користувачів | Лише браузер | Не підлягають відновленню |

### Заходи безпеки

- Всі з'єднання використовують HTTPS (зашифровані)
- Паролі не зберігаються в коді
- Конфіденційні дані зберігаються в захищених змінних середовища Vercel
- Регулярні оновлення безпеки від Vercel
- API-ключ email зберігається безпечно (не видно в коді)

### Змінні середовища

Наступні секретні значення зберігаються безпечно в Vercel (не в коді):

| Змінна | Призначення |
|--------|-------------|
| `RESEND_API_KEY` | Автентифікація для сервісу email |
| `ADMIN_EMAIL` | Email-адреса для отримання результатів оцінювання |

Їх можна оновити в панелі керування Vercel у розділі Project Settings → Environment Variables.

## Додаток А: Глосарій

| Термін | Визначення |
|--------|------------|
| **API** | Application Programming Interface — спосіб комунікації між різним програмним забезпеченням |

## Додаток В: Усунення несправностей

### Поширені проблеми та рішення

| Проблема | Можлива причина | Рішення |
|----------|-----------------|---------|
| Email не отримано | Email у папці спаму | Перевірте папку спам/небажана пошта |
| Email не отримано | Досягнуто денний ліміт Resend | Зачекайте до наступного дня (скидається опівночі UTC) |
| Завантаження PDF не працює | Браузер блокує спливаючі вікна | Дозвольте спливаючі вікна для цього сайту |
| Оцінювання не зберігається | localStorage заповнено/вимкнено | Очистіть дані браузера або використайте інший браузер |
| Сайт не завантажується | Збій Vercel (рідко) | Перевірте status.vercel.com |

### Перевірка доставки email

1. Увійдіть до панелі Resend (https://resend.com)
2. Перейдіть до розділу "Emails"
3. Перегляньте всі надіслані email зі статусом доставки
4. Зелений = доставлено, Жовтий = в очікуванні, Червоний = не вдалося
